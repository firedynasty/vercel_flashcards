# Implementation Plan: Recent Files Picker & Expanded Setup for learn-google

**Branch**: `002-learn-google-recent-picker` | **Date**: 2026-09-10 | **Spec**: [spec.md](spec.md)

**Input**: User description — port the "Recent ▾" dropdown from `learn-chinese-tts.html`
into `learn-google.html`, and make the setup section start expanded on page load.

## Summary

Two changes to `learn-google.html`:

1. **Expanded setup on load**: Remove `collapsed` from `#setupSection` initial class and
   change the initial arrow from `▶` to `▼`. Zero JS changes needed — pure HTML edit.

2. **Recent ▾ dropdown**: Port the dropdown pattern from `001-gdrive-recent-picker`
   (already delivered in `learn-chinese-tts.html`). Adapt element IDs, status helper name,
   and load function call signature for `learn-google.html`.

## Technical Context

**Language/Version**: Vanilla JavaScript ES2020+ (no transpile step)

**Primary Dependencies**:
- Google Identity Services (`accounts.google.com/gsi/client`) — existing, CDN
- Google Drive Files API v3 — existing endpoint, reused `gdriveAccessToken`
- xlsx.js — existing, CDN (no change)

**Storage**: In-memory only (no localStorage, no server state)

**Testing**: Manual browser validation per `quickstart.md`

**Target Platform**: Mobile browser (Samsung Galaxy Z Fold, ≥320px viewport)

**Project Type**: Static web application — single HTML file

**Performance Goals**: Dropdown list appears within 3 seconds on mobile data

**Constraints**:
- All changes in `learn-google.html` only
- No build pipeline
- Touch-first, ≥44px tap targets, no horizontal overflow on 320px
- Feature gated behind sign-in; existing flashcard unaffected

**Key differences from learn-chinese-tts.html** (for porting):

| Item | learn-chinese-tts.html | learn-google.html |
|------|------------------------|-------------------|
| Status helper | `setStatus(msg)` | `setGStatus(msg)` |
| Load function | `loadSpreadsheet(id)` | `gdriveLoadSpreadsheet(fileId, fileName)` |
| Search input ID | `searchInput` | `gSearchInput` |
| Search btn ID | `searchBtn` | `gSearchBtn` |
| Sheet select ID | `sheetSelect` | `gSheetSelect` |
| Auth success (where to wire recentBtn) | `gdriveSignIn()` callback in `learn-chinese-tts` | `gdriveInitClient()` callback |
| Sign-out (where to disable recentBtn) | `gdriveSignIn()` sign-out branch | `gdriveSignIn()` sign-out branch (same pattern) |
