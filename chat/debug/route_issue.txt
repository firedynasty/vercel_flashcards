Route issue: /learn-chinese-tts showed the main page (2026-09-23)
=====================================================================

Symptom
-------
With `vercel dev`, http://localhost:3000/learn-chinese-tts loaded flashcards.html
(the main page) instead of learn-chinese-tts.html.
http://localhost:3000/learn-chinese-tts.html worked fine.

Cause
-----
vercel.json has no cleanUrls, so every page needs its own rewrite. The last
rule is a catch-all:

    { "source": "/(.*)", "destination": "/flashcards.html" }

learn-chinese-tts only had the ".html" rewrite, not the extensionless one, so
"/learn-chinese-tts" fell through to the catch-all and served flashcards.html.

Fix
---
Added the extensionless rewrite above the catch-all:

    { "source": "/learn-chinese-tts", "destination": "/learn-chinese-tts.html" },

Rule for new pages
------------------
Always add BOTH rewrites, above the catch-all:

    { "source": "/my-page.html", "destination": "/my-page.html" },
    { "source": "/my-page",      "destination": "/my-page.html" },

Rules are matched top to bottom, so anything below the catch-all never runs.

Still missing the extensionless route (only work with ".html"):
  /role-playing, /learn-chinese, /musicindex, /classical_player
Pages with no rewrite at all (e.g. learn-korean-tts-2) only load via ".html".

Alternative: add "cleanUrls": true to vercel.json so "/page" serves
"page.html" automatically, instead of adding a pair of rewrites per page.
