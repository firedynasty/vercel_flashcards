# Implementation Plan: Google Doc Import & Recent Docs for read-literature

**Branch**: `003-read-literature-gdoc` | **Date**: 2026-09-10 | **Spec**: [spec.md](spec.md)

**Input**: Port Google sign-in + "Recent ▾" dropdown pattern from `learn-google.html` into
`read-literature.html`, adapted for Google Docs instead of Sheets, and rewire
`#pasteImportBtn` to detect Google Doc URLs in the clipboard and import via Drive export API.

## Summary

Three additions to `read-literature.html`:

1. **Google sign-in setup section**: A collapsible div (starts expanded) with Sign In / Sign Out
   button and inline status paragraph. Styled to match the page's parchment aesthetic.

2. **Upgraded `#pasteImportBtn`**: Detects a Google Doc URL in clipboard → extracts doc ID →
   fetches plain text via Drive export → calls existing `importTxt()`. Falls back to existing
   behaviour otherwise (no Google URL, or not signed in).

3. **Recent ▾ dropdown**: Lists up to 10 recently viewed Google Docs via Drive Files API,
   imports selected doc the same way as the paste-URL flow.

## Technical Context

**Language/Version**: Vanilla JavaScript ES2020+ (no transpile step)

**Primary Dependencies**:
- Google Identity Services (`accounts.google.com/gsi/client`) — new CDN import for this file
- Google Drive Files API v3 — `files.list` (recent docs) + `files.export` (fetch as plain text)
- No additional libraries needed; xlsx.js not required (no spreadsheet parsing)

**Storage**: In-memory only (no localStorage, no server state)

**Testing**: Manual browser validation per `quickstart.md` (10 scenarios)

**Target Platform**: Mobile browser (Samsung Galaxy Z Fold, ≥320px viewport)

**Constraints**:
- All changes confined to `read-literature.html` only
- No build pipeline
- Touch-first, ≥44px tap targets, no horizontal overflow on 320px
- Google integration fully optional; existing export/import/.txt flows unchanged

## Porting Differences from learn-google.html

| Item | learn-google.html | read-literature.html |
|------|-------------------|----------------------|
| Status helper | `setGStatus(msg)` | `setGdocStatus(msg)` |
| Load function | `gdriveLoadSpreadsheet(id, name)` | `gdocImport(fileId)` |

| File select action | Load spreadsheet cells | Fetch text export → `importTxt()` |
| Setup section CSS | `.setup-section`, `.setup-row`, teal/grey palette | New `.gdoc-setup`, `.gdoc-row` styled with `--paper`/`--ink`/`--line` vars |
| Status element ID | `#gStatus` | `#gdocStatus` |
| Recent btn ID | `#recentBtn` | `#gdocRecentBtn` |
| Recent dropdown ID | `#recentDropdown` | `#gdocRecentDropdown` |
| Search input/btn | Present (unchanged) | Not applicable |
| Sheet select | Present | Not applicable |
| Auth callback | `gdriveInitClient()` | `gdocInitClient()` |
| Sign-in/out fn | `gdriveSignIn()` | `gdocSignIn()` |
| Access token var | `gdriveAccessToken` | `gdriveAccessToken` (same name OK, isolated scope) |

## Implementation Strategy

3. Add HTML: gdoc-setup section above `.toolbar`
4. Add JS: `gdriveAccessToken`, `gdocInitClient()`, `gdocSignIn()`, DOMContentLoaded sign-in wiring
5. Add JS: `extractGDocId()`, `gdocImport()`, rewire `#pasteImportBtn`
6. US3: Add `_gdocDismissListener`, `fetchRecentDocs()`, `openGdocDropdown()`, `closeGdocDropdown()`, `_registerGdocDismissListener()`, gdocRecentBtn click handler

### What This Ports From 002-learn-google-recent-picker

The dropdown JS/CSS (`fetchRecentFiles` → `fetchRecentDocs`, `openRecentDropdown` → `openGdocDropdown`, etc.) and CSS classes are direct copies with three targeted substitutions:
- `setGStatus(` → `setGdocStatus(`
- `gdriveLoadSpreadsheet(f.id, f.name)` → `gdocImport(f.id)`
- Drive query mime type: `spreadsheet` → `document`
- Element IDs: `recentBtn` → `gdocRecentBtn`, `recentDropdown` → `gdocRecentDropdown`
