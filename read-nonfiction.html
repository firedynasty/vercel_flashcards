      Paste / Import Guide

      Basic format

      Start each idea with a line beginning with #. Everything after it, up to the next # line, becomes that idea's notes. A bare paste like this works directly — no wrapper needed.

      #topic
notes...

#topic
notes...

#topic
notes...

      Nesting (## )

      Use ## for a sub-point of the idea above it. Nesting only shows as indentation in this app's Intro(i) outline — the main "Key Ideas" list stays flat either way.

      #topic
notes...

##sub-point
nested notes...

      Importing from a Google Doc: use actual Heading 1 / Heading 2 paragraph styles for the same effect — Google Docs' own Markdown autocorrect converts typed #/## into those styles anyway, and the level survives either way.
